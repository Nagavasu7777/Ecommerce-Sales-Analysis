# E-commerce Sales Analysis

## Project Overview
This project focuses on analyzing e-commerce sales data to identify sales trends, customer behavior, product performance, and country-wise revenue.

## Tools & Technologies
- Python
- Pandas
- Power BI
- MySQL

## Project Workflow

### 1. Raw Dataset
Used the Online Retail II dataset containing transaction-level sales records.

### 2. Data Cleaning
- Handled missing values.
- Removed duplicate records.
- Processed invoice and transaction data.
- Handled cancellation records.
- Created additional date-related columns.
- Calculated revenue.

### 3. Power BI Dashboard
Created an interactive dashboard to analyze:
- Total Revenue
- Total Orders
- Total Customers
- Total Products
- Total Quantity
- Average Order Value
- Monthly Sales Trends
- Top Products
- Country-wise Sales
